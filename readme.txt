# Elimination - Territory War Style Game

A turn-based tactical game built in Godot 4.2, inspired by Territory War 2.

## Features
- Two teams of 4 stick figure soldiers (Red vs Blue)
- Fully destructible terrain
- Turn-based combat with movement limits
- Three weapons: Gun, Rocket Launcher, Grenade
- Soldiers can be killed by damage or knocked off screen
- Movement is based on distance from turn start (walking back recovers movement)
- Health displayed above each soldier's head

## Controls
- **Arrow Keys (Left/Right)**: Move soldier
- **Arrow Key (Up)**: Jump
- **Space**: Enter aiming mode / Fire weapon
- **W/S**: Aim up/down while in aiming mode
- **1**: Select Gun (25 damage, fast, small destruction)
- **2**: Select Rocket Launcher (50 damage, explosive, large destruction)
- **3**: Select Grenade (40 damage, arcing throw, large destruction)
- **Enter**: End turn early
- **F11**: Toggle fullscreen
- **R**: Restart game
- **Escape**: Quit

## How to Play
1. Each turn, control one soldier from your team
2. Use arrow keys to move (limited movement per turn)
3. Press Space to enter aiming mode
4. Use W/S to aim up/down
5. Press Space again to fire
6. Turn ends after attacking
7. Eliminate all enemy soldiers to win!

## Running the Game
Open the project in Godot 4.2+ and press F5 to run.
